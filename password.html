    Device settings
    How this works: the Deterministic tab turns your passphrase + personal key + a site name into the same password every time, on any device, with no lookup table and nothing stored - that's the whole point of it. The Vault tab exists because switching algorithms changes the output, so it lets you pick which algorithm was active when an old password was generated. The Random tab is a completely separate, ordinary CSPRNG generator for one-off passwords that don't need to be reproducible. The Lab tab is a full cryptography toolkit - encryption, secret links, hashing, signatures, Shamir secret sharing, 2FA codes - built on your browser's own WebCrypto plus the same Argon2id engine, and checked against official test vectors every time the page loads. The Device tab is the only opt-in exception to "nothing stored": it keeps your latest password per site in this browser, double-encrypted with a non-exportable device key plus your passkey or PIN, so it can't be opened anywhere else. Every value on this page is recomputed fresh on each click. This file makes zero network requests, and its Content-Security-Policy makes the browser itself refuse any connection - so even a bug couldn't send your data anywhere. It works offline and can be saved to your own computer and opened directly.
    Remember this exactly
    Your passphrase and personal key are never saved, transmitted, or recoverable - not by this app, not by anyone. If you forget them, every password you've ever generated from them is gone for good. Write them down somewhere safe - a physical note, or a separate password manager entry - before you rely on this for anything real.

    Welcome to ForgeKey
    • For the best experience please use the Chromium based web browsers.
    • Deterministic tab - the same passphrase, personal key, site, and settings always forge the exact same password. Nothing about that password is ever saved.
    • Vault tab - rebuild a password you generated before, using the same inputs plus the month it was made for.
    • Random tab - a normal one-off random password, no passphrase needed.
    • Lab tab - a cryptography toolkit: check password strength, encrypt text or files (and send them as secret links), hashes, digital signatures, secret sharing, 2FA codes, encoders - and live self-tests against the official standards.
    • Device tab - optionally keep your latest password per site on this device, unlocked with your fingerprint, face or a PIN. It can't be read on any other device.
    • Your passphrase and key never leave this page and are never written to disk. A recovery code only remembers your public settings, never your secrets.
